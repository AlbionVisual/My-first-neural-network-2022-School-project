# Моя первая нейронная сеть

Последние изменения файлов были в мае 2022. Я был тогда в 10-ом классе.

Моя первая нейронная сеть - персептрон с метрикой 3-2-1. Это простая нейронная сеть выбора из двух вариантов - идти ли на праздник - в зависимости от 3-ёх величин: хорошее ли настроение, погода и будет ли аклоголь. Принимает на вход три булевых значения, и возвращает одно действительное значение.

Программа инициализирует пустую нейронную сеть со случайными весами. Потом проводит цикл обучений, в каждом из которых считает общую ошибку и методом обратного распространения ошибки (упрощённого) высчитывает новые веса каждого нейрона.

В консоль выводиться уровень ошибки в каждой итерации цикла, а в конце показывает результат работы на всём наборе, а также последнюю, итоговую ошибку:
